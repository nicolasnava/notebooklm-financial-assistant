# 📸 Galeria do Projeto e Entregáveis

Nesta página, apresento os registros visuais de todos os recursos gerados pelo **NotebookLM** durante o Bootcamp Bradesco GenAI & Dados. Cada material foi construído a partir da curadoria de 30 fontes estratégicas.

A IA gerou uma jornada visual intitulada **"A Jornada para o Domínio Financeiro"**. Este guia prático baseia-se em materiais do Banco Central do Brasil para auxiliar na navegação pelo mundo das finanças pessoais.
