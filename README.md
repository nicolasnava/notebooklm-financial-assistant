# 💰 Agente Financeiro Inteligente: Orçamento Pessoal com NotebookLM

Este repositório contém o projeto desenvolvido para o **Bootcamp Bradesco GenAI & Dados**, uma iniciativa de 52 horas em parceria com a **DIO** focada em Inteligência Artificial Generativa e análise de dados. 

---

## 🎯 Objetivo do Projeto
O desafio propôs a criação de um caderno temático que funcionasse como um miniguia de estudo dinâmico. Utilizei o **NotebookLM** para realizar a curadoria de fontes financeiras e transformar textos estáticos em materiais de revisão interativos e multimodais.

## 📚 Fontes de Conhecimento
O caderno foi alimentado por uma base de dados selecionada para cobrir desde a teoria até a prática:
* **Relatório de Deep Research**: Tendências e análises geradas por IA sobre o mercado financeiro.
* **5 Métodos para Organizar a Vida Financeira**: Guia com estratégias como a regra 50-30-20.
* **5 Ferramentas para Digitalizar Gastos**: Manual sobre tecnologia aplicada ao controle financeiro.
* **Objetivos de Aprendizagem**: Documento norteador para alinhar as respostas da IA às metas do bootcamp.

## 🤖 Recursos de IA Generativa Aplicados
Utilizei as ferramentas do NotebookLM para gerar produtos que facilitam a retenção de conhecimento:
* **🎧 Podcast (Audio Overview)**: Intitulado *"Deixe de Sonho Vire Projeto Financeiro Sólido"*, uma síntese inteligente em formato de áudio.
* **🗂️ Flashcards (Fichas)**: Geração de **70 cartões didáticos** para revisão espaçada de conceitos cruciais.
* **🗺️ Mapa Mental & Relatórios**: Estruturação visual dos pilares para um planejamento de longo prazo.
* **✍️ Resumo Estruturado**: Síntese automática destacando a reserva de emergência e mudança de hábitos.

## 🛠️ Prompts de Estudo Ativo
Variações de prompts foram testadas para extrair o máximo das fontes, como:
* *"Quais são os pilares essenciais para elaborar um planejamento financeiro pessoal de longo prazo?"*
* *"Como aplicar a regra 50-30-20 em um cenário de alta inflação baseando-se nos textos?"*
